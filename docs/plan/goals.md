# goals — プロジェクトの目的と完成形

作成日時: 2026-07-24 22:14
更新日時: 2026-11-01 16:45

## 目的

朝起きたときに見るデスクトップアプリを作る。地球儀の上に風の流れを表示しながら、設定した地点のその日の天気と一週間の天気を、ニュース原稿のような文章と表で伝える。

## 完成形

- 起動すると地球儀が設定地点へ寄り、今日の天気ニュースと週間予報が読める。
- 数値と文章は実データに基づき、出典と作成方法が画面で分かる。
- 通信先はすべて無料のデータソースで、LLM はローカルで動かす。

## 重視すること

- **正確さ:** 数値はテンプレートで作り、LLM に触らせない。LLM の要約が怪しいときは気象庁の原文を出す。
- **軽さ:** LLM は必要なときだけ読み込み、VRAM を占有し続けない。他アプリの llama-server には触れない。
- **見て楽しい:** `wind-map` の風の描画を活かす。

## 対象外

- 現在地の自動取得(地点はユーザーが設定する)
- 商用利用(Open-Meteo の無料枠は非商用)
