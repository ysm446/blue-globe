## ニュース文の作り方

朝に見るアプリなので、普段は今日の話をする。18時からは明日の話に切り替える。

1. 見出し、現在の天気、その日の天気と最高・最低気温、降水確率は、テンプレートで作る。
   - 今日の値は、過去の時間帯を含めず、今の時刻から今日の終わりまでの時間別予報から求める(週間予報の「今日」も同じ)。
2. 見通しは、気象庁の文からその日の分を取り出す。夕方の発表などで今日の分がなければ、明日の分を使う。
   - 1文なら LLM を通さず、文末を「見込みです」に揃える。
   - 「〜見込みです。このため、〜」は「〜ため、〜」とルールでつなぐ。
   - それでも複数の文が残るときだけ LLM で1文にまとめる。
3. LLM の出力は検査し、落ちたら気象庁の原文を表示する。
   - 原文にない語の追加、雷や時間帯などの欠落、地域名の欠落、書き出しと文末、長さを見る。
4. 気象庁の文がない地点(海外、奄美地方)は、見通しの文を出さない。その日の文と週間予報で伝わるため。

ルールを優先するのは、`gemma-4-E4B` に全文を任せると「晴れ」が「晴」に崩れるなどの誤りが出たため。

Open-Meteo の予報値と気象庁の文は別の予報なので、食い違うことがある(2026-11-01 の東京: 予報値は「晴れ時々曇り」、気象庁は「曇り」)。出典は画面に明記している。

## 今後の候補(優先順)

1. 国内の週間予報と今日の天気を、気象庁の予報に揃える(`forecast/{office}.json`)。Open-Meteo との食い違いがなくなる。
2. 検査の精度を、台風や大雪の日の実データで確かめる。
3. 朝の自動起動(Windows のログイン時や指定時刻)。
4. 「今日の見どころ」(気温差、雨の開始時刻、強風)の自動判定。
5. 読み上げ、複数地点の切り替え。
6. llama.cpp の導入スクリプト(現在は手元のビルドをコピーして配置)。
