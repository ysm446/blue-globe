# 場面の保存(スナップショット)

作成日時: 2026-11-07 00:40
更新日時: 2026-11-07 00:40

スクリーンショットの代わりに、あとで同じ場面を地球儀の上に作り直せるよう、時刻、カメラ、表示の状態と、そのときのデータ(雲、風、地点の天気)を保存する機能の設計。画像と違い、作り直した場面は回したり寄ったりできる。まだ実装していない。

## 方針

- **データそのものを保存する:** 時刻だけを残してあとで取り直す方法は使わない。風と雲の補正に使う GFS は NOMADS から約 10 日で消え、地点の天気は予報の更新で値が変わるため。保存した時点で、その時刻のデータを写して残す。
- **画面に出ていた値をそのまま残す:** 地点の天気は、そのとき画面に出ていた値(`NewsReport`)を加工せずに保存する(goals.md の「数値はデータソースの値をそのまま出す」)。
- **ツアーとは別の機能:** 保存の一覧はツアーのパネルとは別のパネルにする。ツアーの途中で保存しても、ツアーの情報(ハイライト、字幕、ツアーで動かした時刻)は入れない。
- **F12 とは別の操作:** F12(と Shift+F12)のスクリーンショットはそのまま。場面の保存は右上のボタンと Ctrl+S で行う。

## 操作

- **ボタン:** 右上のアイコンの列(音楽、デモ、更新、設定)の、更新の左に置く。アイコンはしおり(ブックマーク)の形にする。カメラの絵は、カメラのパネルや地域ビューの「カメラ」の切り替え、スクリーンショットと紛らわしいので使わない。説明は「この場面を保存(Ctrl+S)」。
- **キー:** Ctrl+S。今は何にも使っていない(Ctrl+数字は視点の保存、S は地球を回す操作で Ctrl を押していると反応しない)。入力欄にフォーカスがあるときと設定画面を開いているときは受け付けない(`acceptsInput` と同じ)。
- **知らせ:** スクリーンショットと同じ形の短い知らせ(「場面を保存しました」)。データの用意に数秒かかることがあるので、押したらすぐ「保存しています…」を出す。
- **太陽系の視点:** 視点の保存と同じく保存できない(知らせで伝える)。

## 保存するもの

| もの | 中身 | 大きさの目安 |
|---|---|---|
| 時刻 | 見ていた時刻。今を見ていたら保存した時刻、時刻のスライダーで過去を見ていたらその時刻。ツアーで動かした時刻は使わない | — |
| カメラ | 視点の保存と同じ形(`CameraBookmark`。地球ビューか地域ビュー、緯度経度、距離、方角、傾き、巡航) | 数百 B |
| 表示 | 表示モード(通常・天気・風速)、地点(`WeatherLocation`)、見ていた都市(都市のラベルで選んでいたとき) | 数百 B |
| 見た目の設定 | 焦点距離、F 値、被写界深度、露出補正、自動露出、雲の見た目、海岸線と国境線など、画面の見え方に効く設定 | 数 KB |
| 雲 | 見ていた時刻の雲マップ(衛星から作ったもの。取れなければ GFS)と、その出典と時刻 | 8MB(圧縮前) |
| 風 | 見ていた時刻の GFS の風(`records`)と、その出典と時刻 | 1MB 前後 |
| 地点の天気 | 画面に出ていた `NewsReport` そのまま(今の天気、24 時間、週間、日の出・日の入り) | 数 KB |
| 小さな画像 | 一覧に出す縮小画像(幅 320 の JPEG) | 数十 KB |
| 版 | アプリのバージョン(`package.json`)、雲マップの作り方の版(`MAP_VERSION`) | — |

- **雲と風は両方保存する:** 雲と風は、そのモードに入ったときに初めて取得する(`map-layers.ts`)。画面が持っているものだけを保存すると、通常モードで撮った場面に雲が入らない。保存のときに、見ていた時刻の雲と風をメインプロセスで用意する(今と同じ `clouds:get` と `wind:get` の処理。過去の時刻なら `cloud-cache/past` と `wind-cache/past` を使う)。
- **保存しないもの:** 太陽、月、星、惑星の位置(時刻から計算できる)。地表の画像と標高(変わらない)。

## 保存先

`data/snapshots/<id>/` に 1 場面ずつフォルダを作る(`data/` は Git の対象外)。

```
data/snapshots/scene-20261106-144100/
  scene.json       時刻、カメラ、表示、見た目の設定、地点の天気、出典、版
  clouds.bin.gz    雲マップ (gzip)
  wind.json.gz     風 (gzip)
  thumb.jpg        一覧の画像
```

- 雲マップは晴れた場所の 0 が多いので、gzip で小さくなる見込み(どのくらい縮むかは作るときに測る)。
- フォルダごとに独立させ、フォルダを消せば場面が消える。ほかの PC へ写すこともできる。
- 書き込みは一時フォルダに書いてから名前を変え、途中で落ちても壊れた場面を残さない。

## 再現(第 2 段階)

- **一覧:** 右上に「保存した場面」のパネル(ツアーのパネルとは別)。縮小画像、日時、地点を並べ、押すと再現、ゴミ箱で削除(ツアーと同じく 2 回押すと消える)。
- **再現の状態:** 保存したデータに差し替え、カメラを保存した姿勢へ飛ばし、時刻を保存した時刻にし、表示モードと見た目の設定を合わせる。上に「11月6日 14:41 に保存した場面」の帯と「今に戻る」を出す。地球儀は自由に動かせる。最新データの自動の更新は止める。
- **時刻のスライダー:** 保存した時刻に固定し、薄く表示して触れないようにする(消すより、時刻の決まった場面を見ていることが伝わる)。時計は保存した日時を出す。理由は 3 つ。保存しているのはその時刻 1 つ分の雲と風だけで、ほかの時刻のデータがない(取り直せるのも約 10 日前まで)。太陽だけを動かすと、その時刻にはなかった雲と光の組み合わせを本物のように見せてしまう。今のスライダーは今から 24 時間前までの目盛りで、古い場面の時刻はその外になる。
  - 候補: 太陽の向きだけを動かす別の操作(「雲と風は保存した時刻のまま」と明示する)。保存のときに前後数時間のデータも残し、その範囲でスライダーを動かせるようにする(1 時間分で約 9MB 増える)。
- **戻る:** 帯の「今に戻る(Esc)」か Esc キーで、開く前の状態に戻す(ツアーを Esc で終えるのと同じ操作)。戻すのは時刻(今、またはスライダーで見ていた過去の時刻)、雲と風、地点の天気、見た目の設定。カメラは戻さず、今の位置のままにする(開いたあとに寄ったり回したりしていたら、急に飛ぶと落ち着かない。元の場所へは「ホームへ戻る」か視点の呼び出しで戻れる)。見た目の設定は再現の間だけ変え、設定ファイルは書き換えない。入力欄にフォーカスがあるときと設定画面を開いているときの Esc では閉じない。
- **ツアーとの関係:** 場面を開いたらツアーは止め、ツアーを始めたら場面は閉じる。同時には開かないので、Esc が閉じるものは 1 つに決まる。
- **見た目は完全には同じにならない:** アプリを更新して描き方が変わると、同じデータでも見た目が少し変わる。データとカメラを再現するものとし、版を見て古い作り方のデータだと分かるようにしておく。

## 進め方

1. **保存:** ボタン、Ctrl+S、知らせ、`data/snapshots/` への書き出し。再現がなくてもデータは残り始める。
2. **一覧と再現:** パネル、再現の状態、今に戻る、削除。
3. (候補)保存した場面をツアーの場面の行き先に使う、MCP から保存や再現をする。

## 決めていないこと

- 雲を GFS で埋めた場面(衛星を取れなかったとき)や、風を取れなかった場面も保存するか(今の考え: 保存し、出典に書いておく)。
- 保存の数や容量の上限を設けるか。
- 見ていた都市(都市のラベルで選んだ天気)を、地点の代わりに保存するか、両方保存するか。
