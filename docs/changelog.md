# 変更履歴

作成日時: 2026-11-01 19:40
更新日時: 2026-11-04 03:02

## 未リリース

- 被写界深度を追加した(通常・天気モード)。地球を地球儀の模型に見立てて撮ったように、ピントの合った画面の中心から奥や手前へ離れるほどぼかす。地域ビューで寄るほど強く、地球ビューではほとんどぼけない。設定の「カメラ」タブで、オンオフ、F 値、地球儀の大きさを変えられる(既定はオン、F4、1.0 m)(2026-11-04)。
- `start.bat` の `.venv` の作成を、Python 3.13 がなければ `py -3`、`python` の順に探すようにし、パッケージの導入が途中で止まっていても次回に続きを入れるようにした(2026-11-04)。
- 地球ビューにキー操作を追加した。A/D で 1 回押すごとに 1 段ずつ地球の回転を変え(手を離しても回り続け、逆のキーで止まる)、W/S を押している間は南北へ動き、矢印キーでその向きの次の都市へ移る。上の中央の案内を地球ビューでも出す(2026-11-04)。
- 設定の各項目にマウスを乗せるか、キーボードで選ぶと、説明と既定値がポップアップで出るようにした(2026-11-04)。
- 設定のグラフィックスに「宇宙の青み」を追加した。背景の宇宙の青さを 0%(写真どおりの真っ黒)から 100%(従来の濃さ)まで変えられる(2026-11-04)。
- 地球の周りの大気の光を、昼の面を正面に見たときに明るく、夜の面を見たときに暗くなるよう直し、縁を細くした。月を小さく暗くして実際の見え方に近づけた。立体の雲の影が太陽が真上のときに横へずれないようにし、平らな雲の影が境目の近くで長く伸びすぎないようにした。日の出と日の入りの近くでは地表も赤みを帯びるようにした(2026-11-03)。
- 白いすりガラス調の雲と朝日を組み合わせたアイコンを採用し、アプリのウィンドウアイコンに設定した。画像は `assets/icons/weather-news-v2.png`。
